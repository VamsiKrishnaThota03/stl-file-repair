# Pinned for reproducibility. The previous `>=` ranges meant a fresh install
# could silently pick up a new major — trimesh 5 changed mesh-processing
# defaults and numpy 2 changed dtype-promotion rules — so a run that worked
# last month could behave differently today with no change here.
#
# Every pin below still supports Python 3.11, which is the floor CI tests.
# numpy 2.5 and scipy 1.18 both require >=3.12, so they are deliberately not
# used: dropping 3.11 support to chase a minor version is a worse trade than
# staying one release back. Bump deliberately; Dependabot opens the PRs.
trimesh==5.2.0
numpy==2.5.4
matplotlib==3.11.2
scipy==1.18.1
